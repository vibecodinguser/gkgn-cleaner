# GKGN Cleaner

Утилита для конвертации PDF таблиц географических объектов из [Реестра ГКГН](https://kadastr.ru/services/gkgn/) в структурированные Excel файлы с автоматической очисткой и нормализацией координат.

## Описание

Скрипт обрабатывает PDF файлы из папки `source/`, извлекает таблицы с помощью [docling](https://github.com/DS4SD/docling), выполняет очистку и нормализацию данных координат, и сохраняет результаты в `result/` с префиксом `converted_`.

### Основные возможности

- **Извлечение таблиц** из PDF используя docling
- **Конвертация координат** из формата DDM (Градусы и десятичные минуты) → DD (Десятичные градусы)
- **Сохранение** результатов в Excel формате

## Установка

```bash
pip install -r requirements.txt
```

### Требования

- Python 3.8+
- docling
- pandas
- openpyxl

## Использование

### Базовый запуск

```bash
python cleaner.py
```

Скрипт автоматически:
1. Найдёт все `.pdf` файлы в папке `source/`
2. Обработает их по очереди
3. Сохранит результаты в `result/converted_*.xlsx`
4. Выведет прогресс обработки и количество извлеченных строк

## Обработка координат

### Входные форматы координат

- DMM: `55°45'30`, `55°45.5'`, `55°45'30"`, `55 45 30`
- Десятичные градусы: `55.75833`, `55.75833`
- Смешанные форматы с буквами, пробелами, символами (º, °, ′, ', и т.д.)

### Выходной формат

Все координаты нормализуются в **десятичные градусы** с точностью до 6 знаков после запятой:

```
55.758333
```

### Обработка таблиц

Скрипт также обрабатывает следующие поля:
- **Столбцы 5-6 (Координаты)**: автоматическое разделение координат если они объединены в один столбец, нормализация формата DMM → DD
- **Столбец 7 (Номенклатура листа)**: извлечение кода в формате `X-XX-XXX` (например `О-37-145`)
- **Первые 2 строки**: автоматически удаляются (служебная информация)
- **Столбцы**: переименовываются в стандартные наименования ГКГН

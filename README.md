# GKGN Cleaner

Утилита для конвертации PDF таблиц географических объектов из
[Реестра ГКГН](https://kadastr.ru/services/gkgn/) в структурированные Excel файлы с автоматической
очисткой и нормализацией координат.

## Описание

Скрипт обрабатывает PDF файлы из папки `source/`, извлекает таблицы с помощью
[docling](https://github.com/DS4SD/docling), выполняет очистку и нормализацию данных координат,
и сохраняет результаты в `result/` с префиксом `converted_`.

### Основные возможности

- **Извлечение таблиц** из PDF используя docling
- **Сохранение** результатов в Excel формате

## Установка

```bash
pip install -r requirements.txt
```

### Требования

- Python 3.12+
- docling
- pandas
- openpyxl
- tqdm

## Использование

### Базовый запуск

```bash
python cleaner.py
```

Скрипт автоматически:

1. Найдёт все `.pdf` файлы в папке `source/`
2. Обработает их по очереди
3. Сохранит результаты в `result/converted_*.xlsx`
4. Выведет прогресс обработки и количество извлеченных строк

## Обработка координат

- DMM: `55°45'30`, `55°45.5'`, `55°45'30"`, `55 45 30`
- Десятичные градусы: `55.75833`, `55.75833`
- Смешанные форматы с буквами, пробелами, символами (º, °, ′, ', и т.д.)

Все координаты нормализуются в **десятичные градусы** с точностью до 6 знаков после запятой `55.758333`
